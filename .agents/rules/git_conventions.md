# Git and Code Commenting Guidelines

1. **Automatic Git Commits and Push**:
   - Every time meaningful changes or requested features are implemented and verified, automatically stage, commit, and push to the remote repository (`git push origin main`).
2. **Commit Message Format**:
   - Write commit titles and descriptions strictly in **English**.
   - Keep messages short, clean, and concise using Conventional Commits (e.g., `feat: enhance category navigation`, `fix: badge wrapping on mobile`).
   - Do not include verbose or lengthy descriptions.
3. **Code Comments**:
   - All comments in code files must be written in **English**.
